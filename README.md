# Advanced Android

Lab experiments in Android development: AIDL services, audio, permissions and sensors. Each folder is a standalone Android Studio project with its own README.

| Folder | Topic |
| --- | --- |
| [AIDL](AIDL) | Ex.No:2 Create a simple application client and server service using AIDL interface in android studio. |
| [Audio](Audio) | Ex.No: 3 Develop a simple application to play and control the audio file in android studio. |
| [Permission](Permission) | Ex.No: 6 Create a simple application to request storage and camera permission at RunTime using android studio. |
| [Proximity Sensor](Proximity%20Sensor) | Ex.No: 5 Develop a simple application for proximity sensor using Sensor Manager in android studio. |
| [Sensor List](Sensor%20List) | Ex.No: 4 Develop a simple application to display the available sensor in android mobile devices using Sensor Manager in android studio. |
